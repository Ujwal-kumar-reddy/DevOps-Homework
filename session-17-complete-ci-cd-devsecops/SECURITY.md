# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| 1.0.x   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project:
1. Please do NOT file a public issue.
2. Send an email directly to the project security maintainer.
3. Include detailed steps to reproduce the vulnerability, sample inputs, and potential impact.
4. Security patches will be prioritized and verified via automated SAST, SCA, and Trivy container scan gates before release.
